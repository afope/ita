# Map data

`lagos-island.json` is the street network of Lagos Island used by the hero
canvas. It is derived from [OpenStreetMap](https://www.openstreetmap.org)
data, © OpenStreetMap contributors, and is available under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

It contains roads from motorways down to residential streets, split at
junctions and simplified, plus the Lagos Island shoreline and a few street
labels. Coordinates are projected to map units (0–10000 across the width).
